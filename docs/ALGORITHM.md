# RailJourneyOptimizer Algorithm

## Version 1

### Supported

- Direct Journey
- Two Ticket Journey
- Journey Score
- Top 2 Recommendations

---

## Version 2

- Three Ticket Journey
- Four Ticket Journey
- Same Coach Priority
- Lower Berth Preference
- Mixed Class
- Duplicate Removal
- Better Ranking
- Faster Search

---

## Algorithm Flow

User Journey Request

↓

Fetch Train Route

↓

Fetch Chart Vacancy

↓

Analyze Every Vacant Berth

↓

Generate Ticket Combinations

↓

Calculate Journey Score

↓

Sort by Journey Score

↓

Return Top 2 Recommendations
